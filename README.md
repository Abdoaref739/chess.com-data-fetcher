# Chess.com Profiles Fetcher
## What??
It is a fan-made website for getting users' data on chess dot com using chessAPI, this idea specifically got my attention because I wanted to make a project that is simple, but also chess-related, and teach me new skills in coding.
## What is the Techstack?
Just HTML, CSS, and JS
## How does it work?
In the homepage, y'all can see four boxes, about the project, leaderboard, account fetcher (the main function), and a box for future features. 
You can click on whatever box and see the magic
At the bottom, you can see my acount fetched in there.
## I mean, how the main function work??
Aha okay, make sense
When u enter a real account name, it will be send to an API as a request, then get all the data back as a response, and show it to the world on the website.
